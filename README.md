# קריוקי לגיטרה

ספר שירים לגיטרה: מילים, אקורדים מעליהן, פס פריטה (↓↑) ודיאגרמות אצבעות. "נגן" גולל ומדגיש בקצב.

## הפעלה
- לחיצה כפולה על `index.html` (עובד בלי שרת), או שרת סטטי: `python -m http.server 4173`.
- בטלפון: לפתוח את הכתובת המפורסמת ואז "הוסף למסך הבית" — האפליקציה נשמרת ועובדת גם בלי אינטרנט.
  כשיש אינטרנט היא תמיד נטענת בגרסה העדכנית (רשת קודם, עם גיבוי מהמטמון).
- פרסום עדכון: `git push` ל-`main` — GitHub Pages מתעדכן תוך כדקה. אם משנים רשימת קבצים, מעלים את `VERSION` ב-`sw.js`.

## הוספת שיר
במסך הראשי "＋ שיר חדש". הפורמט (ChordPro-קל):
```
{title: שם}  {artist: ..}  {bpm: 90}  {time: 4/4}  {strum: D - D U - U D U}  {bars: 2}  {capo: 2}
{section: בית}
[Am]שלום [C]עולם        <- אקורד לפני המילה שמעליה הוא יושב
שורה ארוכה יותר |4      <- |N = כמה תיבות לשורה הזו
```
פריטה: `D` מטה, `U` מעלה, `-` מנוחה, `X` השתקה. קצבים: 4/4, 3/4, 6/8, 2/4.
שירי משתמש נשמרים רק במכשיר (localStorage). גיבוי/שחזור: כפתורים בתחתית המסך הראשי.

## שירים מובנים (`data/songs.js`)
רק טקסטים בנחלת הכלל (מקרא, תפילה, הגדה, המנון). ההרמוניה והפריטה בסיסיות ושלי. הטקסטים הוקלדו מהזיכרון — לבדוק.

## מבנה
`js/parser.js` טקסט→שיר · `js/engine.js` שעון מוזיקלי ומטרונום · `js/ui-*.js` מסכים · `js/chords-db.js` צורות אקורדים ·
`js/store.js` שמירה · `data/songs.js` שירים · `tests/run.js` בדיקות (`node tests/run.js`) · `tools/gen-icons.js` אייקונים.

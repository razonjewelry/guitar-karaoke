# קריוקי לגיטרה

ספר שירים לגיטרה: מילים, אקורדים מעליהן, פס פריטה (↓↑) ודיאגרמות אצבעות.
**"התחל" = הקשבה:** האפליקציה מקשיבה למיקרופון, והשיר מתקדם רק כשמנגנים נכון את האקורד המסומן — היא מאשרת (ירוק + רטט) ועוברת לבא. אין שעון ואין שיר שרץ לבד.

## איך זה עובד
- הצעד הנוכחי = האקורד המסומן בשיר (זהוב). כדי לאשר: פריטה חדשה של האקורד הנכון (גם אקורד שחוזר פעמיים דורש פריטה חדשה).
- **ספירת פריטות:** כל פריטה שאתה מנגן נספרת (גם חלשה, גם למעלה), ופס הפריטה מתקדם איתך: ירוק = נוגן, מסגרת זהב = הפריטה הבאה בדפוס.
  🥁 **חופשי** = עוברים לאקורד הבא ברגע שהאקורד נכון. 🥁 **דפוס מלא** = עוברים רק אחרי שהאקורד נכון *וגם* סיימת את כל הפריטות של הדפוס (למשל 6/6).
  הכיוון (↓↑) הוא הדרכה בלבד — מהצליל אי אפשר לדעת אם פרטת למעלה או למטה.
- שגוי: "שמעתי X — צריך Y", בלי עונש. פריטות נוספות של האקורד הקודם לא נחשבות שגיאה ולא נספרות על הבא. כפתורים: ⏮ ⏭ · לחיצה על שורה = קפיצה אליה.
- מד העוצמה והציון ("🎤 Am 92%") מראים מה המיקרופון שומע. 🎚 רגישות (נמוכה/רגילה/גבוהה): לא מזהה פריטות/אקורדים — להעלות; מאשר או סופר סתם — להוריד.
- **הזיהוי:** (1) גילוי פריטה = spectral flux על ספקטרום קצר, מנורמל לרצפת הרעש (לא תלוי בעוצמת המיקרופון), עם סף שמסתגל לרעש ולפריטות האחרונות;
  (2) לכל פריטה מנתחים חלון נקי של 256ms אחרי ההתקפה -> פסגות ספקטרום עם אינטרפולציה -> כרומה עם קיזוז כוונון והסרת רצפת רעש ->
  השוואה לתבניות של אקורדי השיר בלבד. דורש https/localhost והרשאת מיקרופון.

## הפעלה
- בטלפון: לפתוח את הכתובת המפורסמת, ואז "הוסף למסך הבית" — האפליקציה נשמרת ועובדת גם בלי אינטרנט.
  כשיש אינטרנט היא תמיד נטענת בגרסה העדכנית (רשת קודם, עם גיבוי מהמטמון).
- מקומית: `python -m http.server 4173` (המיקרופון לא עובד מ-`file://`).
- פרסום עדכון: `git push` ל-`main` — GitHub Pages מתעדכן תוך כדקה. אם משנים רשימת קבצים, מעלים את `VERSION` ב-`sw.js`.

## הוספת שיר
במסך הראשי "＋ שיר חדש". הפורמט (ChordPro-קל):
```
{title: שם}  {artist: ..}  {time: 4/4}  {strum: D - D U - U D U}  {capo: 2}
{section: בית}
[Am]שלום [C]עולם        <- אקורד לפני המילה שמעליה הוא יושב
```
פריטה: `D` מטה, `U` מעלה, `-` מנוחה, `X` השתקה. קצבים: 4/4, 3/4, 6/8, 2/4. אקורדים נתמכים בזיהוי: מז'ור, מינור, 7, m7, maj7, sus4 (ובס עם `/` נחשב לפי האקורד).
שירי משתמש נשמרים רק במכשיר (localStorage). גיבוי/שחזור: כפתורים בתחתית המסך הראשי.

## שירים מובנים (`data/songs.js`)
רק טקסטים בנחלת הכלל (מקרא, תפילה, הגדה, המנון). ההרמוניה והפריטה בסיסיות ושלי. הטקסטים הוקלדו מהזיכרון — לבדוק.

## מבנה
`js/parser.js` טקסט→שיר · `js/fft.js` · `js/chroma.js` כרומה והתאמת אקורד · `js/strum.js` גילוי ומנתח פריטות (זרם) ·
`js/stepper.js` שופט הפריטות וצעדי השיר · `js/listen.js` מיקרופון ·
`js/ui-*.js` מסכים · `js/chords-db.js` צורות אקורדים · `js/store.js` שמירה · `data/songs.js` שירים ·
`tests/run.js` בדיקות (`node tests/run.js`) · `tools/gen-icons.js` אייקונים.
